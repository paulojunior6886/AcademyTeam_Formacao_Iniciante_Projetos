# Exemplos — Pseudocódigo x Python

## Variáveis

### Pseudocódigo

```text
nome <- "Ana"
idade <- 18
```

### Python

```python
nome = "Ana"
idade = 18
```

## Decisão

### Pseudocódigo

```text
SE idade >= 18 ENTÃO
    ESCREVA "Maior de idade"
FIMSE
```

### Python

```python
if idade >= 18:
    print("Maior de idade")
```

## Repetição

### Pseudocódigo

```text
PARA numero DE 1 ATÉ 5 FAÇA
    ESCREVA numero
FIMPARA
```

### Python

```python
for numero in range(1, 6):
    print(numero)
```
